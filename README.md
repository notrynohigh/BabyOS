# BabyOS Project Generator

自动生成 BabyOS 嵌入式项目的工具。

## 功能特性

- **全平台支持**：Windows（主要目标）、Linux、macOS
- **交互式生成**：命令行和 GUI 两种模式
- **支持多种 MCU 厂商**：ST、Nationstech、Mindmotion、ESPRESSIF 等
- **智能解析**：自动解析 BabyOS 代码结构，提取设备和 HAL 接口信息
- **一键生成**：Makefile、链接脚本、启动代码、配置文件

## 快速开始

### 方式一：命令行

```bash
# 列出支持的厂商
python3 babyos_project_generator.py --list-vendors

# 列出某厂商的芯片
python3 babyos_project_generator.py --list-chips --vendor st

# 生成 STM32 项目
python3 babyos_project_generator.py \
    --bos-root /path/to/BabyOS \
    --vendor st \
    --chip STM32F10X_MD \
    -o my_stm32_project

# 生成 ESP32 项目
python3 babyos_project_generator.py \
    --vendor espressif \
    --chip ESP32C3 \
    -o my_esp32_project
```

### 方式二：GUI（Windows 推荐）

双击 `babyos_generator_gui.py` 或：

```bash
python3 babyos_generator_gui.py
```

### 方式三：Windows 批处理

```bat
generate.bat --vendor st --chip STM32F10X_MD -o myproject
```

## 生成的项目结构

```
myproject/
├── Makefile                    # 构建系统
├── README.md                   # 项目说明
├── config/
│   └── b_config.h             # BabyOS 配置
├── src/
│   ├── main.c                 # 应用入口
│   ├── startup.c              # 启动代码
│   └── stm32f10x_md_FLASH.ld # 链接脚本
└── bos/ -> /path/to/BabyOS    # 符号链接（需手动创建）
```

## 使用步骤

1. **生成项目**
   ```bash
   python3 babyos_project_generator.py --vendor st --chip STM32F10X_MD -o myproject
   ```

2. **创建 bos 链接（Windows）**
   ```bat
   cd myproject
   mklink /J bos C:\path\to\BabyOS
   ```

3. **配置（可选）**
   ```bash
   make config  # 启动 Kconfig 界面
   ```

4. **编译**
   ```bash
   make
   ```

5. **烧录**
   ```bash
   make flash
   ```

## 高级用法

### 指定 BabyOS 路径

```bash
# 环境变量
export BABYOS_ROOT=/path/to/BabyOS

# 命令行参数
python3 babyos_project_generator.py --bos-root /path/to/BabyOS ...
```

### 自定义项目名称

```bash
python3 babyos_project_generator.py \
    --vendor st \
    --chip STM32F10X_MD \
    --name my_custom_project \
    -o output_dir
```

### 生成但不编译

```bash
python3 babyos_project_generator.py --vendor st --chip STM32F10X_MD -o myproject
cd myproject
# 手动查看/编辑文件后再编译
make
```

## 注意事项

1. **Windows 符号链接**：Windows 上无法直接创建指向目录的符号链接，需要用 `mklink /J` 创建目录联接
2. **工具链**：Makefile 默认使用 `arm-none-eabi-gcc`，需根据实际安装调整
3. **配置覆盖**：生成的 `b_config.h` 是初始配置，可用 `make config` 进一步定制

## 故障排除

### BabyOS 目录未找到

```
Error: BabyOS directory not found.
```

解决：使用 `--bos-root` 参数显式指定路径

### Windows 上 bos 链接失败

Windows 默认不允许非管理员创建符号链接。解决方式：

1. 以管理员身份运行命令提示符
2. 或使用 Git Bash / MSYS2
3. 或手动复制 BabyOS 目录

### 编译报错

检查：
1. `b_config.h` 是否正确生成
2. 工具链是否安装（`arm-none-eabi-gcc --version`）
3. Include 路径是否正确（Makefile 中的 BOS_ROOT）
