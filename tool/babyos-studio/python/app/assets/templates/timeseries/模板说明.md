# 时序数据模板说明

本模板列名 **全列示范**：`ts,ch0,ch1,ch2,label`

## 三种导入形态（与 FR-2.8 对齐）

| 形态 | 列结构 | 备注 |
|------|--------|------|
| 仅通道 | `ch0,ch1,ch2` | 必须；后续标签阶段手动圈选 |
| 通道 + 时间戳 | `ts,ch0,ch1,ch2` | ts 仅用于可视化、可选 |
| 通道 + 时间戳 + 标签 | `ts,ch0,ch1,ch2,label` | label 列存在时，**导入即按 FR-2.6 RLE 自动生成片段** |

## 列定义

- `ts`     浮点秒；可选；非等间隔也可
- `ch*`    浮点采样值；通道名在导入界面可重命名
- `label`  整数类别 id；可选；缺失时所有样本在标签阶段手动标注
