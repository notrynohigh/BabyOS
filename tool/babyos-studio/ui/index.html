数据预览

▾ CSV 文件格式说明

上传的 CSV 文件应包含以下格式：第一行为列名，后续行为数据。如需自动分段，请包含 label 列。

时序模式 (timeseries) 示例：

timestamp accel_x accel_y accel_z gyro_x gyro_y gyro_z
0.0000.12-0.459.810.01-0.020.00
0.0100.15-0.429.790.02-0.010.01
0.0200.18-0.389.820.010.00-0.01
0.0300.21-0.359.800.000.010.02
.....................

• 第一列通常为时间戳（可选）
• 中间列为传感器数据（加速度、陀螺仪等）
• 采样率应保持一致

表格模式 (table) 示例：

feature_1 feature_2 feature_3 feature_4 label
1.234.567.890.12normal
2.345.678.900.23normal
3.456.789.010.34abnormal
4.567.890.120.45abnormal
...............

• 每行为一个样本
• 前几列为特征列
• 最后一列为标签列（可选）

请先导入至少一个数据文件

传输文件
